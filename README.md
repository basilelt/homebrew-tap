# Homebrew tap for Overseer

[Overseer](https://github.com/basilelt/overseer) runs and supervises your AI coding agents side by side.

```sh
brew tap basilelt/tap
brew install --cask overseer   # desktop app (macOS)
brew install overseer          # daemon and CLI (macOS, Linux)
```

The formula and cask are updated automatically by each Overseer release.
